PERSONAL FILE UTILITY

yewon-sync

사용자의 PC에 있는 폴더를 사용자의 Google Drive로 복사하는 개인용 도구입니다. 사용자가 명시적으로 실행할 때 rclone을 통해 새 파일과 변경된 파일을 업로드합니다.

사용 방식

파일의 원래 형식과 폴더 구조를 유지합니다. 로컬에서 삭제한 파일은 Google Drive에 보관하며, Google Drive의 내용을 로컬로 내려받아 덮어쓰지 않습니다.

Google 계정 연결

Google OAuth를 사용하며, 앱이 생성하거나 사용자가 이 앱에 허용한 파일을 다루는 drive.file 권한을 요청합니다. 인증 정보는 사용자의 PC에 저장됩니다.

이 웹사이트는 도구의 안내 페이지입니다. 로그인, 파일 업로드 또는 동기화를 실행하는 웹서비스가 아닙니다.
