개인정보처리방침

적용일: 2026년 10월 12일

yewon-sync는 개인용 PC에서 사용자의 Google Drive로 파일을 복사하는 도구입니다. 이 안내는 도구가 사용하는 데이터와 관리 방법을 설명합니다.

접근하는 정보와 사용 목적

사용자가 지정한 로컬 파일, 파일명, 폴더 경로, 크기, 수정 시간 및 체크섬을 처리합니다. Google Drive에서는 앱이 생성하거나 사용자가 허용한 파일의 내용과 메타데이터에 접근하여 업로드, 변경 확인 및 전송 검증을 수행합니다. 이 정보는 사용자가 요청한 파일 복사와 결과 확인을 위해서만 사용합니다.

Google 권한과 인증 정보

https://www.googleapis.com/auth/drive.file 범위를 사용합니다. OAuth 인증 정보는 사용자 PC의 접근이 제한된 설정 폴더에 저장됩니다. Google 비밀번호를 수집하거나 저장하지 않습니다.

저장과 전달

파일은 사용자 PC에서 Google Drive로 전송됩니다. yewon-sync가 운영하는 별도의 파일 수집 서버는 없습니다. 실행 로그에는 파일 경로, 전송 상태 및 오류 정보가 기록될 수 있으며 PC에 보관됩니다. 사용자가 Codex 등 보조 도구에서 실행하면 해당 실행 환경에 상태와 로그가 표시될 수 있습니다. 별도로 설정한 작업 기록 백업 및 보조 도구의 데이터 처리는 해당 서비스의 정책과 사용자 설정을 따릅니다.

제한된 사용

Google API로 받은 정보는 요청된 동기화 기능 제공에 사용합니다. 광고, 판매 또는 범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

보관과 삭제

Google Drive의 사본은 사용자가 직접 삭제할 때까지 보관됩니다. 로컬 원본 삭제는 Drive 사본 삭제로 이어지지 않습니다. 로컬 인증 정보와 로그는 PC에서 삭제할 수 있으며, Google 계정 연결 관리에서 앱의 접근 권한을 해제할 수 있습니다. 권한 해제만으로 이미 업로드된 파일이 삭제되지는 않습니다.

이 안내 웹사이트

이 사이트에는 로그인 양식, 파일 업로드 기능, 자체 분석 스크립트 또는 추적 쿠키가 없습니다. 호스팅 제공자인 GitHub는 GitHub 개인정보처리방침에 따라 접속 정보를 처리할 수 있습니다.
